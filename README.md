# Smart Temperature-Based Fan Automation Using ESP8266

## 📌 About the Project

Smart Temperature-Based Fan Automation Using ESP8266 is an IoT-based smart home automation project designed to automatically control a fan based on room temperature.

Using an ESP8266 microcontroller and a temperature sensor, the system continuously measures the surrounding temperature. When the temperature increases beyond a predefined threshold, the fan automatically turns ON. When the temperature decreases, the fan can turn OFF or adjust according to the configured temperature range.

The collected temperature data is transmitted through Wi-Fi to the KiwisIoT platform, allowing users to monitor real-time temperature readings and fan status through an online dashboard.

This project helps improve indoor comfort, reduce unnecessary electricity consumption, and demonstrates how IoT technology can support intelligent home automation.
